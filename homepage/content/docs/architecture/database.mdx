# Database Schema

Mello uses PostgreSQL as its primary data store with GORM for object-relational mapping. The schema follows a hierarchical structure from workspaces down to individual card items.

## Entity Relationship Diagram

```
┌─────────────┐       ┌─────────────┐
│    Users    │───────│  Workspaces │
└─────────────┘       └─────────────┘
      │                     │
      │                     │
      ▼                     ▼
┌─────────────┐       ┌─────────────┐
│ WorkspaceM. │       │   Boards    │
└─────────────┘       └─────────────┘
                            │
              ┌─────────────┼─────────────┐
              ▼             ▼             ▼
        ┌─────────┐   ┌─────────┐   ┌─────────────┐
        │  Lists  │   │ Labels  │   │CustomFields │
        └─────────┘   └─────────┘   └─────────────┘
              │
              ▼
        ┌─────────┐───────┬───────────┬──────────────┐
        │  Cards  │       │           │              │
        └─────────┘       ▼           ▼              ▼
              │     ┌──────────┐ ┌──────────┐ ┌─────────────┐
              │     │CardLabels│ │CardMembers│ │ Attachments │
```

## Core Tables

### Users

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `email` | VARCHAR | Unique email address |
| `password` | VARCHAR | Bcrypt hashed password |
| `full_name` | VARCHAR | Display name |
| `bio` | TEXT | User biography |
| `avatar_url` | VARCHAR | Avatar image URL |
| `created_at` | TIMESTAMP | Creation timestamp |
| `updated_at` | TIMESTAMP | Last update timestamp |

### Workspaces

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `name` | VARCHAR | Workspace name |
| `description` | TEXT | Workspace description |
| `owner_id` | UUID | FK to Users |
| `created_at` | TIMESTAMP | Creation timestamp |
| `updated_at` | TIMESTAMP | Last update timestamp |

### Workspace Members

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `workspace_id` | UUID | FK to Workspaces |
| `user_id` | UUID | FK to Users |
| `role` | VARCHAR | `admin` or `member` |
| `created_at` | TIMESTAMP | Join timestamp |

### Boards

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `workspace_id` | UUID | FK to Workspaces |
| `title` | VARCHAR | Board title |
| `description` | TEXT | Board description |
| `background_color` | VARCHAR | Hex color code |
| `background_image` | VARCHAR | Background image URL |
| `is_starred` | BOOLEAN | Starred status |
| `show_card_covers` | BOOLEAN | Show cover images |
| `position` | INTEGER | Display order |
| `created_at` | TIMESTAMP | Creation timestamp |
| `updated_at` | TIMESTAMP | Last update timestamp |

### Lists

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `board_id` | UUID | FK to Boards |
| `title` | VARCHAR | List title |
| `position` | INTEGER | Display order |
| `is_collapsed` | BOOLEAN | Collapsed state |
| `is_archived` | BOOLEAN | Archived status |
| `created_at` | TIMESTAMP | Creation timestamp |
| `updated_at` | TIMESTAMP | Last update timestamp |

### Cards

| Column | Type | Description |
|--------|------|-------------|
| `id` | UUID | Primary key |
| `list_id` | UUID | FK to Lists |
| `title` | VARCHAR | Card title |
| `description` | TEXT | Card description |
| `cover_image` | VARCHAR | Cover image URL |
| `position` | INTEGER | Display order |
| `due_date` | TIMESTAMP | Due date |
| `is_completed` | BOOLEAN | Completion status |
| `is_archived` | BOOLEAN | Archived status |
| `created_by` | UUID | FK to Users |
| `created_at` | TIMESTAMP | Creation timestamp |
| `updated_at` | TIMESTAMP | Last update timestamp |

| Column | Type | Description |

## Indexes

Key indexes for performance:

```sql
-- User lookups
CREATE UNIQUE INDEX idx_users_email ON users(email);

-- Workspace member lookups
CREATE INDEX idx_workspace_members_workspace_id ON workspace_members(workspace_id);
CREATE INDEX idx_workspace_members_user_id ON workspace_members(user_id);

-- Board filtering
CREATE INDEX idx_boards_workspace_id ON boards(workspace_id);

-- List ordering
CREATE INDEX idx_lists_board_id ON lists(board_id);

-- Card filtering
CREATE INDEX idx_cards_list_id ON cards(list_id);
CREATE INDEX idx_cards_created_by ON cards(created_by);

-- Notification queries
CREATE INDEX idx_notifications_user_id ON notifications(user_id);
CREATE INDEX idx_notifications_is_read ON notifications(user_id, is_read);
```

## Migrations

GORM handles migrations automatically on startup:

```go
db.AutoMigrate(
    &models.User{},
    &models.Workspace{},
    &models.WorkspaceMember{},
    &models.Board{},
    &models.List{},
    &models.Card{},
    &models.Label{},
    &models.CardLabel{},
    &models.CardMember{},
    &models.Comment{},
    &models.Checklist{},
    &models.ChecklistItem{},
    &models.CustomField{},
    &models.Attachment{},
    &models.Notification{},
)
```

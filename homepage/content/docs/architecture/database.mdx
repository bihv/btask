# Database Schema

## Entity Relationship

### Core Entities

- **Users**: Thông tin người dùng
- **Workspaces**: Không gian làm việc
- **Boards**: Bảng Kanban
- **Lists**: Danh sách trong board
- **Cards**: Thẻ công việc

### Supporting Entities

- **Labels**: Nhãn màu cho cards
- **Comments**: Bình luận
- **Checklists**: Danh sách kiểm tra
- **ChecklistItems**: Các item trong checklist
- **CustomFields**: Trường tùy chỉnh
- **Attachments**: File đính kèm
- **Notifications**: Thông báo

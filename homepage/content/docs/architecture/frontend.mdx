# Frontend Architecture

The frontend is built with Next.js 14 using the App Router, providing server-side rendering, client-side navigation, and a modern React development experience.

## Tech Stack

| Technology | Purpose |
|------------|---------|
| **Next.js 14** | React framework with App Router |
| **React 18** | UI library with Server Components |
| **Ant Design 5** | UI component library |
| **Zustand** | Lightweight state management |
| **React Query** | Server state & data fetching |
| **dnd-kit** | Drag and drop functionality |
| **TypeScript** | Type safety |

## State Management Strategy

### Server State (React Query)
Used for data that comes from the API:

```typescript
// Fetching boards
const { data: boards, isLoading } = useQuery({
  queryKey: ['boards', workspaceId],
  queryFn: () => api.get(`/workspaces/${workspaceId}/boards`),
});

// Mutations with cache invalidation
const createBoard = useMutation({
  mutationFn: (data) => api.post(`/workspaces/${id}/boards`, data),
  onSuccess: () => {
    queryClient.invalidateQueries(['boards', workspaceId]);
  },
});
```

### Client State (Zustand)
Used for UI state and local interactions:

```typescript
// Auth store
interface AuthStore {
  user: User | null;
  token: string | null;
  login: (email: string, password: string) => Promise<void>;
  logout: () => void;
}

export const useAuthStore = create<AuthStore>((set) => ({
  user: null,
  token: localStorage.getItem('token'),
  login: async (email, password) => {
    const { data } = await api.post('/auth/login', { email, password });
    set({ user: data.user, token: data.token });
  },
  logout: () => set({ user: null, token: null }),
}));
```

## API Client

Centralized API configuration with Axios:

```typescript
// lib/api.ts
const api = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL,
});

api.interceptors.request.use((config) => {
  const token = localStorage.getItem('token');
  if (token) {
    config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

api.interceptors.response.use(
  (response) => response.data,
  (error) => {
    if (error.response?.status === 401) {
      // Handle unauthorized
    }
    return Promise.reject(error);
  }
);
```

## Routing Structure

| Route | Description |
|-------|-------------|
| `/` | Landing page |

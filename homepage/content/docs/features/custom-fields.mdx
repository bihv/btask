# Custom Fields

## Mô tả

Custom Fields cho phép thêm các trường dữ liệu tùy chỉnh cho cards.

## Các loại field

- **Text**: Văn bản
- **Number**: Số
- **Date**: Ngày tháng
- **Checkbox**: Đánh dấu
- **Dropdown**: Lựa chọn từ danh sách

## Quản lý

- Tạo custom fields ở cấp board
- Gán giá trị cho từng card
- Hiển thị trên card preview

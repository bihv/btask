# Boards

## Tạo Board

- Đặt tên board
- Chọn background (màu hoặc ảnh)

## Các tính năng

- **Watch**: Theo dõi board để nhận thông báo
- **Copy**: Sao chép toàn bộ board
- **Archive**: Lưu trữ boards

## Board Settings

- Cập nhật tên, background
- Quản lý labels của board
- Custom fields

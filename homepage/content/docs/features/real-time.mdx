# Real-time Updates

## Mô tả

WebSocket cho phép cập nhật giao diện theo thời gian thực.

## Tính năng

- Cập nhật board khi có thay đổi
- Thông báo real-time
- Đồng bộ nhiều người dùng cùng lúc

## Technical

- WebSocket connection với Go Fiber
- Client reconnection handling

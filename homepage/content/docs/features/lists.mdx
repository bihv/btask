# Lists

## Tạo List

- Thêm list mới vào board

## Các thao tác

- **Move**: Di chuyển vị trí list
- **Copy**: Sao chép list
- **Archive**: Lưu trữ list
- **Expand/Collapse**: Thu gọn list

## Quản lý Cards trong List

- Move all cards
- Sort cards (theo tên, ngày tạo, due date)
- Archive all cards

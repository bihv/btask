# Cards API

## POST /api/lists/:listId/cards
Tạo card.

## GET /api/cards/:id
Lấy card chi tiết.

## PUT /api/cards/:id
Cập nhật card.

## DELETE /api/cards/:id
Xóa card.

## PUT /api/cards/:id/move
Di chuyển card.

## POST /api/cards/:id/labels
Thêm label.

## DELETE /api/cards/:id/labels/:labelId
Xóa label.

## POST /api/cards/:id/members
Thêm member.

## DELETE /api/cards/:id/members/:userId
Xóa member.

## PUT /api/cards/:id/archive
Lưu trữ card.

## PUT /api/cards/:id/unarchive
Khôi phục card.

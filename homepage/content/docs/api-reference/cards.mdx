# Cards API

All card endpoints require authentication. Include the JWT token in the `Authorization` header.

---

## POST /api/lists/:listId/cards

Create a new card in a list.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `listId` | UUID | List ID |

### Request Body

```json
{
  "title": "New Task",
  "description": "Task description",
  "position": 0,
  "due_date": "2024-12-31T23:59:59Z"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | Yes | Card title (1-200 characters) |
| `description` | string | No | Card description |
| `position` | integer | No | Position in list |
| `due_date` | datetime | No | Due date (ISO 8601 format) |

### Errors

| Status | Message |
|--------|---------|
| 400 | Title is required |
| 403 | Access denied |

Get card details including labels, members, comments, and custom field values.

    "due_date": "2024-12-31T23:59:59Z",
    "is_completed": false,
    "is_archived": false,
    "created_by": "uuid",
    "labels": [...],
    "members": [...],
    "comments": [...],
    "custom_field_values": [...],
    "created_at": "2024-01-01T00:00:00Z",
    "updated_at": "2024-01-01T00:00:00Z"

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | Card ID |

### Request Body

```json

  "list_id": "uuid",
  "position": 0
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `list_id` | UUID | Yes | Target list ID |
| `position` | integer | Yes | New position in target list |

{
  "success": true,
  "message": "Card moved successfully"
}

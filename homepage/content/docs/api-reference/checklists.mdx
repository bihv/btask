# Checklists API

Checklists help track sub-tasks within a card. Each checklist contains multiple items that can be marked as complete.

All endpoints require authentication. Include the JWT token in the `Authorization` header.

---

## GET /api/cards/:cardId/checklists

Get all checklists for a card, including their items.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `cardId` | UUID | Card ID |

### Response

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "card_id": "uuid",
      "title": "Tasks",
      "position": 0,
      "items": [
        {
          "id": "uuid",
          "checklist_id": "uuid",
          "content": "Review PR",
          "is_completed": false,
          "position": 0,
          "due_date": null,
          "assignees": [
            {
              "id": "uuid",
              "user_id": "uuid",
              "user": {
                "id": "uuid",
                "full_name": "John Doe",
                "avatar_url": null
              }
            }
          ]
        }
      ],
      "created_at": "2024-01-01T00:00:00Z"
    }
  ]
}
```

## POST /api/cards/:cardId/checklists

Create a new checklist on a card.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `cardId` | UUID | Card ID |

### Request Body

```json
{
  "title": "Tasks"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | Yes | Checklist title |

### Response

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "card_id": "uuid",
    "title": "Tasks",
    "position": 0,
    "items": [],
    "created_at": "2024-01-01T00:00:00Z"
  }
}
```

## POST /api/checklists/:id/items

Add a new item to a checklist.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | Checklist ID |

### Request Body

```json
{
  "content": "Review PR",
  "due_date": "2024-12-31T23:59:59Z",
  "assignee_ids": ["uuid1", "uuid2"]
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `content` | string | Yes | Item description |
| `due_date` | datetime | No | Due date (ISO 8601) |
| `assignee_ids` | array | No | User IDs to assign |

### Response

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "checklist_id": "uuid",
    "content": "Review PR",
    "is_completed": false,
    "position": 0,
    "due_date": "2024-12-31T23:59:59Z",
    "assignees": [...]
  }
}
```

## PUT /api/checklists/:id/items/:itemId

Update a checklist item.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | Checklist ID |
| `itemId` | UUID | Item ID |

### Request Body

All fields are optional:

```json
{
  "content": "Updated content",
  "is_completed": true,
  "position": 2,
  "due_date": "2024-12-31T23:59:59Z",
  "clear_due_date": false,
  "assignee_ids": ["uuid"]
}
```

| Field | Type | Description |
|-------|------|-------------|
| `content` | string | Item description |
| `is_completed` | boolean | Completion status |
| `position` | integer | Position in list |
| `due_date` | datetime | Due date |
| `clear_due_date` | boolean | Set to `true` to remove due date |
| `assignee_ids` | array | User IDs (empty array removes all) |

## POST /api/checklists/:id/items/:itemId/convert

Convert a checklist item to a card. The item's content becomes the card title, and assignees are transferred as card members.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | Checklist ID |
| `itemId` | UUID | Item ID |

### Request Body

```json
{
  "list_id": "uuid"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `list_id` | UUID | Yes | Target list for the new card |

### Response

Returns the newly created card object. The checklist item is deleted after conversion.

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "list_id": "uuid",
    "title": "Review PR",
    "due_date": "2024-12-31T23:59:59Z",
    ...
  }
}
```

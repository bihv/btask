# Labels API

Labels are used to categorize and filter cards on a board. Each board has its own set of labels.

All endpoints require authentication. Include the JWT token in the `Authorization` header.

---

## GET /api/boards/:boardId/labels

Get all labels for a board.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `boardId` | UUID | Board ID |

### Response

```json
{
  "success": true,
  "data": [
    {
      "id": "uuid",
      "board_id": "uuid",
      "name": "Priority",
      "color": "#ff0000",
      "created_at": "2024-01-01T00:00:00Z",
      "updated_at": "2024-01-01T00:00:00Z"
    }
  ]
}
```

---

## POST /api/boards/:boardId/labels

Create a new label on a board.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `boardId` | UUID | Board ID |

### Request Body

```json
{
  "name": "Priority",
  "color": "#ff0000"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `name` | string | No | Label name (can be empty for color-only labels) |
| `color` | string | Yes | Hex color code (e.g., `#ff0000`) |

### Response

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "board_id": "uuid",
    "name": "Priority",
    "color": "#ff0000",
    "created_at": "2024-01-01T00:00:00Z",
    "updated_at": "2024-01-01T00:00:00Z"
  }
}
```

### Errors

| Status | Message |
|--------|---------|
| 400 | Color is required |
| 401 | Access denied |
| 404 | Board not found |

---

## PUT /api/labels/:id

Update a label's name or color.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | Label ID |

### Request Body

All fields are optional:

```json
{
  "name": "Updated Name",
  "color": "#00ff00"
}
```

### Response

```json
{
  "success": true,
  "data": {
    "id": "uuid",
    "board_id": "uuid",
    "name": "Updated Name",
    "color": "#00ff00",
    "created_at": "2024-01-01T00:00:00Z",
    "updated_at": "2024-01-01T00:00:00Z"
  }
}
```

---

## DELETE /api/labels/:id

Delete a label. This will also remove the label from all cards.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | Label ID |

### Response

```json
{
  "success": true,
  "message": "Label deleted successfully"
}
```

---

## Adding/Removing Labels from Cards

To add or remove labels from cards, use the Card API:

- `POST /api/cards/:id/labels` - Add label to card
- `DELETE /api/cards/:id/labels/:labelId` - Remove label from card

See the [Cards API](/docs/api-reference/cards) for details.

# Boards API

## GET /api/workspaces/:workspaceId/boards
Lấy boards trong workspace.

## POST /api/workspaces/:workspaceId/boards
Tạo board.

## GET /api/boards/:id
Lấy board chi tiết.

## PUT /api/boards/:id
Cập nhật board.

## DELETE /api/boards/:id
Xóa board.

## POST /api/boards/:id/watch
Theo dõi board.

## DELETE /api/boards/:id/watch
Bỏ theo dõi.

## POST /api/boards/:id/copy
Sao chép board.

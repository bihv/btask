# Other APIs

## Labels

- `GET /api/boards/:boardId/labels` - Lấy labels
- `POST /api/boards/:boardId/labels` - Tạo label
- `PUT /api/labels/:id` - Cập nhật label
- `DELETE /api/labels/:id` - Xóa label

## Comments

- `GET /api/cards/:cardId/comments` - Lấy comments
- `POST /api/cards/:cardId/comments` - Tạo comment
- `PUT /api/comments/:id` - Cập nhật comment
- `DELETE /api/comments/:id` - Xóa comment

## Checklists

- `GET /api/cards/:cardId/checklists` - Lấy checklists
- `POST /api/cards/:cardId/checklists` - Tạo checklist
- `POST /api/checklists/:id/items` - Thêm item
- `PUT /api/checklists/:id/items/:itemId/toggle` - Toggle item

## Custom Fields

- `GET /api/boards/:boardId/custom-fields` - Lấy custom fields
- `POST /api/boards/:boardId/custom-fields` - Tạo custom field
- `PUT /api/cards/:cardId/custom-fields/:fieldId` - Set giá trị

## Attachments

- `GET /api/cards/:cardId/attachments` - Lấy attachments
- `POST /api/cards/:cardId/attachments` - Upload attachment
- `DELETE /api/attachments/:id` - Xóa attachment

## Notifications

- `GET /api/notifications/` - Lấy thông báo
- `GET /api/notifications/unread-count` - Số chưa đọc
- `PUT /api/notifications/:id/read` - Đánh dấu đã đọc
- `PUT /api/notifications/read-all` - Đánh dấu tất cả đã đọc

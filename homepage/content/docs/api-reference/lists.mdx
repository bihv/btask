# Lists API

All list endpoints require authentication. Include the JWT token in the `Authorization` header.

---

## POST /api/boards/:boardId/lists

Create a new list in a board.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `boardId` | UUID | Board ID |

### Request Body

```json
{
  "title": "To Do",
  "position": 0
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | Yes | List title |
| `position` | integer | No | Position in board |

### Errors

| Status | Message |
|--------|---------|
| 400 | Title is required |
| 403 | Access denied |

### Path Parameters

|-----------|------|-------------|
| `id` | UUID | List ID |

| Parameter | Type | Description |
|-----------|------|-------------|


| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `title` | string | No | Title for copied list (defaults to original) |

## POST /api/lists/:id/sort-cards

Sort cards in a list by a specific criteria.

### Path Parameters

| Parameter | Type | Description |
|-----------|------|-------------|
| `id` | UUID | List ID |

### Request Body

```json
{
  "sort_by": "created_at"
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `sort_by` | string | Yes | Sort criteria (e.g., `created_at`, `title`, `due_date`) |

### Response

```json
{
  "success": true,
  "message": "Cards sorted successfully"
}
```

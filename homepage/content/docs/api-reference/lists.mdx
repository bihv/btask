# Lists API

## POST /api/boards/:boardId/lists
Tạo list.

## PUT /api/lists/:id
Cập nhật list.

## DELETE /api/lists/:id
Xóa list.

## PUT /api/lists/:id/move
Di chuyển list.

## POST /api/lists/:id/copy
Sao chép list.

## POST /api/lists/:id/move-all-cards
Di chuyển tất cả cards.

## POST /api/lists/:id/sort-cards
Sắp xếp cards.

## PUT /api/lists/:id/archive
Lưu trữ list.

## PUT /api/lists/:id/unarchive
Khôi phục list.

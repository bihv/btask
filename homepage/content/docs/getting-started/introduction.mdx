# Introduction to Mello

Mello is a modern, open-source project management application built in the style of Trello. It provides a Kanban-style interface for organizing tasks, collaborating with teams, and managing projects.

## What is Mello?

Mello is a full-stack Trello clone that demonstrates modern web development practices:

- **Full-featured Kanban boards** with drag-and-drop functionality
- **Real-time collaboration** using WebSocket technology
- **Clean, responsive UI** built with Next.js and Ant Design
- **Robust API** powered by Go and Fiber framework
- **Self-hosted** - deploy on your own infrastructure

## Key Features

| Feature | Description |
|---------|-------------|
| **Workspaces** | Organize boards into workspaces with team members |
| **Boards** | Create unlimited Kanban boards with custom backgrounds |
| **Lists & Cards** | Organize work into columns and task cards |
| **Drag & Drop** | Intuitive interface for moving cards and lists |
| **Labels** | Color-coded categorization for cards |
| **Checklists** | Break tasks into sub-items with progress tracking |
| **Due Dates** | Set deadlines and track completion |
| **Comments** | Collaborate and discuss on cards |
| **Attachments** | Upload files and documents to cards |
| **Custom Fields** | Extend cards with custom data |
| **Notifications** | Real-time alerts for activity |
| **WebSocket** | Live updates across all users |

## Tech Stack

### Backend
- **Go** with Fiber framework
- **PostgreSQL** database with GORM
- **JWT** authentication
- **WebSocket** for real-time communication
- **MinIO** for file storage

### Frontend
- **Next.js** with App Router
- **Ant Design** component library
- **Zustand** for state management
- **React Query** for data fetching
- **dnd-kit** for drag and drop

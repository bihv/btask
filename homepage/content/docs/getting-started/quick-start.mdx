# Bắt đầu nhanh

## Clone repository

```bash
git clone https://github.com/your-org/mello.git
cd mello
```

## Chạy với Docker

```bash
docker-compose up -d
```

## Truy cập ứng dụng

- Frontend: http://localhost:3000
- Backend API: http://localhost:8080

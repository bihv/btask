# 📉 Technical SEO Checklist

Danh mục kiểm tra kỹ thuật định kỳ cho website.

- [ ] **Robots.txt**: Cho phép bot truy cập các trang quan trọng, chặn các trang rác.
- [ ] **Sitemap.xml**: Cập nhật đầy đủ các URL mới nhất.
- [ ] **Canonical Tags**: Ngăn chặn trùng lặp nội dung giữa các phiên bản URL.
- [ ] **SSL (HTTPS)**: Bắt buộc để tăng độ tin cậy.
- [ ] **Mobile Friendly**: Giao diện phải responsive 100%.
- [ ] **Schema Markup**: Nhúng JSON-LD để Google hiển thị Rich Snippets (Rating, Price, FAQ).
- [ ] **Core Web Vitals**: Đảm bảo LCP < 2.5s, FID < 100ms, CLS < 0.1.
